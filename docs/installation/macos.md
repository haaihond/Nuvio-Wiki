# macOS Installation

1. **Download the application.** Grab the latest [.dmg installer from the official GitHub releases](https://github.com/NuvioMedia/NuvioDesktop/releases/latest).
2. **Open the disk image.** Double-click the downloaded `.dmg` file.
3. **Install Nuvio.** Drag the Nuvio application into your **Applications** folder.
4. **Launch Nuvio.** Open Nuvio from your Applications folder or Spotlight.

> [!NOTE]
> If macOS displays a gatekeeper warning about an unidentified developer, right-click (or Control-click) the Nuvio app, select **Open**, and click **Open** in the confirmation dialog.

You're all set!
